# osgbhub

İSG (İş Sağlığı ve Güvenliği) yönetim sistemi. İşverenler ve İSG profesyonelleri için risk değerlendirme, saha denetimi, ramak kala / iş kazası kaydı, eğitim–tatbikat takibi ve mevzuat uyumunu tek panelde toplar.

- Platform: web (Vite + React SPA) — şimdilik backend yok, demo modu
- UI dili: Türkçe
- Wordmark: "isg" + vurgulu "hub" (amber-400/500)
- Aksan rengi: amber / hi-vis sarısı — İSG dünyasının ikaz rengi
- Giriş: `/giris` — sol marka paneli (dev ShieldCheck filigranı + 5×5 risk matrisi ürün parçası + hairline'lı özellik listesi), sağ form (kullanıcı adı + şifre + demo doldurma)
